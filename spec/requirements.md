# Requirements

Jira-Lite is a support ticket system for a single organization. This document is the product source of truth for MVP.

## Roles

| Role | Who | Capabilities |
| --- | --- | --- |
| Requester | Employee who needs help | Create tickets, view tickets they created, add comments on those tickets |
| Agent | Support staff | View all tickets, filter/search, assign (including self), change status along allowed transitions, comment |
| Admin | Support lead | Everything an Agent can do, plus manage the user directory (list users; mark active/inactive) |

MVP does **not** include login, SSO, or permission enforcement in the API. The UI and API accept a `reporterId` / `assigneeId` / `authorId` as identifiers. A later phase may add authentication; until then, treat role rules as intended UX, not a security boundary.

## MVP features

1. **Create ticket** — title (required), description, priority (default `MEDIUM`), reporter (user id). New tickets start in status `OPEN` with no assignee.
2. **List tickets** — paginated list with filters: status, priority, assigneeId, reporterId, free-text search on title.
3. **Ticket detail** — show all fields, comments in chronological order, and current status.
4. **Update ticket** — change title, description, priority, assignee, and status (status only via allowed transitions; see [state-machine.md](state-machine.md)).
5. **Assign** — set or clear `assigneeId`. Clearing assignee is allowed in any non-`CLOSED` status.
6. **Comments** — append-only comments on a ticket; no edit or delete in MVP.
7. **Users** — list users for reporter/assignee pickers. Seed or create users out of band for MVP (no public self-registration).

## Functional rules

- Ticket `key` is generated by the server as `TCK-{n}` where `n` is a monotonic integer.
- Status changes must follow [state-machine.md](state-machine.md). Illegal transitions return `409`.
- Closed tickets are read-only except that an Agent/Admin may reopen `CLOSED` → `OPEN`.
- Soft-delete is out of scope; tickets are never deleted in MVP.

## Out of scope (MVP)

- Authentication, authorization, sessions, JWT
- Attachments, watchers, labels, custom fields
- Email/Slack notifications, SLAs, queues
- Multi-project / multi-tenant
- Ticket delete, comment edit/delete
- Real-time (WebSocket) updates
- Analytics dashboards
